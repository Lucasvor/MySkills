# Workspace Files

Use estes formatos quando a skill precisar criar os arquivos de memoria do projeto.

## PROJECT-MISSION.md

```md
# Project Mission

## Objetivo Macro

Ainda nao informado.

## Escopo Atual

- Nao confirmado ainda.

## Fora de Escopo

- Nao confirmado ainda.

## Criterios de Sucesso

- Nao confirmado ainda.

## Ultima Atualizacao

- YYYY-MM-DD: arquivo criado pela skill `process-meeting`.
```

## TEAM-GLOSSARY.md

```md
# Team Glossary

## Pessoas

| Nome | Papel/Area | Fonte | Observacoes |
|---|---|---|---|

## Sistemas e Projetos

| Termo | Significado | Fonte | Observacoes |
|---|---|---|---|

## Siglas e Jargoes

| Termo | Significado simples | Fonte | Observacoes |
|---|---|---|---|

## Questoes em Aberto

- [ ] Termos citados mas ainda nao confirmados.
```

## ACTION-ITEMS.md

```md
# Action Items

## Pendentes

- [ ] YYYY-MM-DD | Acao: ... | Dono: Sem dono confirmado | Prazo: Sem prazo confirmado | Fonte: ...

## Concluidos

- [x] YYYY-MM-DD | Acao: ... | Concluido em: YYYY-MM-DD | Fonte: ...

## Bloqueados

- [ ] YYYY-MM-DD | Acao: ... | Bloqueio: ... | Fonte: ...
```
